Section A

연결 리스트 (Linked Lists)

이 섹션에서 지정된 문제 1개를 풀면 됩니다.

안내 — 각 문제의 프로그램 템플릿은 APAS 시스템에 올라와 있습니다. 반드시 그 템플릿을 사용해서 함수를 구현해야 합니다.

문제 목록

  1. insertSortedLL — 정렬된 리스트에 삽입
  2. alternateMergeLL — 번갈아 끼워 합치기
  3. moveOddItemsToBackLL — 홀수를 뒤로
  4. moveEvenItemsToBackLL — 짝수를 뒤로
  5. frontBackSplitLL — 앞/뒤 절반으로 분리
  6. moveMaxToFront — 최댓값을 맨 앞으로
  7. recursiveReverse — 재귀로 뒤집기

1insertSortedLL

사용자에게 정수 하나를 입력받아, 그 값을 오름차순을 유지하도록 연결 리스트에 삽입하는 C 함수 insertSortedLL()을 작성하세요.

이미 리스트에 존재하는 값이면 삽입하면 안 됩니다. 함수는 새 항목이 들어간 인덱스 위치를 반환하고, 정상적으로 끝내지 못한 경우에는 -1을 반환해야 합니다. 주어지는 연결 리스트는 이미 정렬되어 있거나 비어 있다고 가정해도 됩니다.

함수 원형

int insertSortedLL(LinkedList *ll, int item);

예시

  • 현재 리스트: 2, 3, 5, 7, 9
  • insertSortedLL()에 8을 넣어 호출
  • 결과 리스트: 2, 3, 5, 7, 8, 9

→ 값 8은 인덱스 4에 추가되었으므로 4를 반환합니다.
The value 8 was added at index 4

  • 현재 리스트: 5, 7, 9, 11, 15
  • insertSortedLL()에 7을 넣어 호출
  • 결과 리스트: 5, 7, 9, 11, 15 (변화 없음)

→ 7은 이미 있으므로 삽입에 실패하고 -1을 반환합니다.
The value 7 was added at index -1

2alternateMergeLL

두 번째 리스트의 노드들을 첫 번째 리스트의 한 칸 건너 한 칸(alternate position) 자리에 끼워 넣는 C 함수 alternateMergeLL()을 작성하세요.

두 번째 리스트의 노드는 첫 번째 리스트에 끼워 넣을 자리가 남아 있을 때만 삽입됩니다.

함수 원형

void alternateMergeLL(LinkedList *ll1, LinkedList *ll2);

예시

  • LinkedList1: 1, 2, 3
  • LinkedList2: 4, 5, 6, 7

→ 결과

  • LinkedList1: 1, 4, 2, 5, 3, 6
  • LinkedList2: 7

첫 번째 리스트가 두 번째 리스트보다 길면, 두 번째 리스트는 비게 됩니다.

  • LinkedList1: 1, 5, 7, 3, 9, 11
  • LinkedList2: 6, 10, 2, 4

→ 결과

  • LinkedList1: 1, 6, 5, 10, 7, 2, 3, 4, 9, 11
  • LinkedList2: empty

입출력 예시

(현재 리스트가 Linked list 1: 1, 2, 3 / Linked list 2: 4, 5, 6, 7 인 경우)

Linked list 1: 1 2 3
Linked list 2: 4 5 6 7

Please input your choice(1/2/3/0): 3
The resulting linked lists after merging the given linked list are:
Linked list 1: 1 4 2 5 3 6
Linked list 2: 7
