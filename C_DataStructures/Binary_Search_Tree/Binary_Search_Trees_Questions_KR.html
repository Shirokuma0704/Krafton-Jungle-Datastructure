Section F

이진 탐색 트리 (Binary Search Trees)

이 섹션에서 지정된 문제 1개를 풀면 됩니다.

안내 — 각 문제의 프로그램 템플릿은 APAS 시스템에 올라와 있습니다. 반드시 그 템플릿을 사용해서 함수를 구현해야 합니다.

문제 목록

  1. levelOrderTraversal — 큐로 레벨 순회
  2. inOrderIterative — 스택으로 중위 순회
  3. preOrderIterative — 스택으로 전위 순회
  4. postOrderIterativeS1 — 스택 하나로 후위 순회
  5. postOrderIterativeS2 — 스택 둘로 후위 순회

1levelOrderTraversal

큐를 사용해서 이진 트리를 루트 레벨부터 한 층씩 훑어 출력하는 반복문 C 함수 levelOrderTraversal 을 작성하세요.

큐에 정수를 넣고 뺄 때는 enqueue() 와 dequeue() 만 사용해야 합니다. 시작할 때 큐가 비어 있지 않으면 먼저 비워야 합니다.

함수 원형

void levelOrderIterative(BSTNode *root);

예시

레벨 순회 결과: 20, 15, 50, 10, 18, 25, 80
