Section C

스택과 큐 (Stack and Queues)

이 섹션에서 지정된 문제 1개를 풀면 됩니다.

안내 — 각 문제의 프로그램 템플릿은 APAS 시스템에 올라와 있습니다. 반드시 그 템플릿을 사용해서 함수를 구현해야 합니다.
원본 PDF 여백 메모에 대해 — 원본에는 누군가 빨간 글씨로 적어둔 풀이 힌트가 문제마다 붙어 있습니다. 빠뜨리면 원본과 달라지니까 옮겨는 뒀는데, 먼저 스스로 풀어보시라고 접어두었습니다. 각 문제 아래 “여백 메모 보기”를 눌러야 펼쳐집니다.

문제 목록

  1. createQueueFromLinkedList — 연결 리스트로 큐 만들기
  2. createStackFromLinkedList — 연결 리스트로 스택 만들기
  3. isStackPairwiseConsecutive — 두 개씩 연속인지 검사
  4. reverseQueue — 스택으로 큐 뒤집기
  5. recursiveReverseQueue — 재귀로 큐 뒤집기
  6. removeUntilStack — 지정한 값까지 빼내기
  7. balanced — 괄호 짝 맞추기

1createQueueFromLinkedList

연결 리스트에 저장된 정수를 전부 enqueue 해서 큐(연결 리스트 기반)를 만드는 C 함수 createQueueFromLinkedList()를 작성하세요.

연결 리스트의 첫 번째 노드가 먼저 들어가고, 그다음 두 번째 노드, 이런 순서입니다. 시작할 때 큐가 비어 있지 않으면 먼저 비워야 한다는 점을 잊지 마세요.

함수 원형

void createQueueFromLinkedList(LinkedList *ll, Queue *q);

입출력 예시

현재 연결 리스트가 1, 2, 3, 4, 5 일 때

만들어진 연결 리스트: 1 2 3 4 5
원하는 번호를 입력하세요(1/2/3/0): 2
만들어진 큐: 1 2 3 4 5
여백 메모 보기 (풀이 힌트 · 스포일러) 
ListNode *temp = ll->head;
while (temp != NULL) {
    // 여기서 하고 싶은 걸 한다
    temp = temp->next;
}

2createStackFromLinkedList

연결 리스트에 저장된 정수를 전부 push 해서 스택(연결 리스트 기반)을 만드는 C 함수 createStackFromLinkedList()를 작성하세요.

연결 리스트의 첫 번째 노드가 먼저 push 되고, 그다음 두 번째 노드, 이런 순서입니다. 시작할 때 스택이 비어 있지 않으면 먼저 비워야 합니다.

함수 원형

void createStackFromLinkedList(LinkedList *ll, Stack *stack);

입출력 예시

현재 연결 리스트가 1, 3, 5, 6, 7 일 때

만들어진 연결 리스트: 1 3 5 6 7
원하는 번호를 입력하세요(1/2/3/0): 2
만들어진 스택: 7 6 5 3 1

→ 먼저 넣은 것이 바닥으로 내려가니까 출력 순서가 뒤집힙니다.

여백 메모 보기 (풀이 힌트 · 스포일러) 
ListNode *temp = ll->head;
while (temp != NULL) {
    // 여기서 하고 싶은 걸 한다
    temp = temp->next;
}

3isStackPairwiseConsecutive

스택에 든 숫자들이 두 개씩 짝지어 연속인지 검사하는 C 함수 isStackPairwiseConsecutive()를 작성하세요.

이 함수는 스택에 정수를 넣거나 뺄 때 push()와 pop()만 사용해야 합니다.

함수 원형

int isStackPairwiseConsecutive(Stack *s);

예시

  • 스택: 16 15 11 10 5 4

→ 두 개씩 연속입니다. (16·15 / 11·10 / 5·4)

  • 스택: 16 15 11 10 5 1

→ 두 개씩 연속이 아닙니다. (5·1 이 안 맞음)

  • 스택: 16 15 11 10 5

→ 두 개씩 연속이 아닙니다. (개수가 홀수라 짝이 안 맞음)

여백 메모 보기 (풀이 힌트 · 스포일러)

크기가 홀수면 0 을 반환.
아니면 쌍마다 확인해서, 하나라도 조건에 안 맞으면 0 을 반환.
전부 통과하면 1 을 반환.

4reverseQueue

스택을 사용해서 큐를 뒤집는 C 함수 reverseQueue()를 작성하세요.

스택에 정수를 넣고 뺄 때는 push()와 pop()만, 큐에 정수를 넣고 뺄 때는 enqueue()와 dequeue()만 사용해야 합니다. 시작할 때 스택이 비어 있지 않으면 먼저 비워야 합니다.

함수 원형

void reverseQueue(Queue *q);

예시

큐가 (1, 2, 3, 4, 5) 이면 결과 큐는 (5, 4, 3, 2, 1) 입니다.

여백 메모 보기 (풀이 힌트 · 스포일러)

스택 초기화하는 것을 잊지 말 것.

5recursiveReverseQueue

정수 큐에 저장된 항목의 순서를 뒤집는 재귀 C 함수 recursiveReverseQueue()를 작성하세요.

함수 원형

void recursiveReverseQueue(Queue *q);

예시

큐가 (1, 2, 3, 4, 5) 이면 결과 큐는 (5, 4, 3, 2, 1) 입니다.

여백 메모 보기 (풀이 힌트 · 스포일러) 
int temp;
if (q->ll.head == NULL) return;
temp = dequeue(q);
recursiveReverseQueue(q);
enqueue(q, temp);

※ 원본 여백에 적힌 코드가 사실상 정답입니다.

6removeUntilStack

정수 스택에서 지정한 값이 처음 나올 때까지 값을 전부 pop 해내는 C 함수 removeUntilStack()을 작성하세요.

함수 원형

void removeUntilStack(Stack *s, int value);

예시

  • 스택: (1, 2, 3, 4, 5, 6, 7) — 맨 왼쪽이 top
  • removeUntilStack()을 value = 4 로 호출
  • 결과 스택: (4, 5, 6, 7)
  • 스택: (10, 20, 15, 25, 5) — 맨 왼쪽이 top
  • removeUntilStack()을 value = 15 로 호출
  • 결과 스택: (15, 25, 5)

→ 지정한 값 자체는 남습니다. 그 값이 새 top 이 됩니다.

여백 메모 보기 (풀이 힌트 · 스포일러)

for 문도 while 처럼 break 로 빠져나올 수 있다.
s->ll.size == 0 인 경우를 고려할 것.

7balanced

()[]{} 문자로 이루어진 식의 괄호 짝이 맞는지 판정하는 C 함수 balanced()를 작성하세요.

함수 원형

int balanced(char *expression);

예시

괄호의 순서와 개수가 모두 맞아서 짝이 맞는 식:

  • ()
  • ([])
  • {[]()[]}

짝이 맞지 않는 식:

  • {{)]
  • [({{)])

입출력 예시

1: 문자열 입력:
2: ()[]{} 로 이루어진 식의 괄호가 맞는지 확인:
0: 종료:

원하는 번호를 입력하세요(1/0): 1
괄호가 맞는지 확인할 식을 공백 없이 입력하세요: {[]()[]}
{[]()[]}
괄호가 맞습니다!

원하는 번호를 입력하세요(1/0): 0
원하는 번호를 입력하세요(1/0): 1
괄호가 맞는지 확인할 식을 공백 없이 입력하세요: [({{)])
[({{)])
괄호가 안 맞습니다!

원하는 번호를 입력하세요(1/0): 0
여백 메모 보기 (풀이 힌트 · 스포일러)

스택을 쓴다.
{ [ ( 이면 스택에 push.
아니면 } ] ) 가 스택 top 과 짝이 맞을 때 pop.
마지막에 스택이 비었는지 확인.
