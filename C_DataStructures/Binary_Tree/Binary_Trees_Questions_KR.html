Section E

이진 트리 (Binary Trees)

이 섹션에서 지정된 문제 1개를 풀면 됩니다.

안내 — 각 문제의 프로그램 템플릿은 APAS 시스템에 올라와 있습니다. 반드시 그 템플릿을 사용해서 함수를 구현해야 합니다.
원본 PDF 여백 메모에 대해 — 원본에는 누군가 빨간 글씨(중국어)로 적어둔 풀이 힌트가 문제마다 붙어 있습니다. 빠뜨리면 원본과 달라지니까 옮겨는 뒀는데, 먼저 스스로 풀어보시라고 접어두었습니다. 각 문제 아래 “여백 메모 보기”를 눌러야 펼쳐집니다.

문제 목록

  1. identical — 두 트리가 구조적으로 같은가
  2. maxHeight — 최대 높이
  3. countOneChildNodes — 자식이 하나뿐인 노드 세기
  4. sumOfOddNodes — 홀수 전부 더하기
  5. mirrorTree — 좌우로 뒤집기
  6. printSmallerValues — 기준보다 작은 값 출력
  7. smallestValue — 최솟값
  8. hasGreatGrandchild — 증손자가 있는 노드

1identical

두 이진 트리 tree1 과 tree2 가 구조적으로 같은지 판정하는 재귀 C 함수 identical() 을 작성하세요. 같으면 1, 아니면 0 을 반환합니다.

두 이진 트리가 구조적으로 같다는 것은, 둘 다 비어 있거나, 또는 둘 다 비어 있지 않으면서 왼쪽 서브트리와 오른쪽 서브트리가 서로 닮은 경우입니다. (같은 값을 가진 노드들이 같은 모양으로 배치되어 있다는 뜻입니다.)

함수 원형

int identical(BTNode *tree1, BTNode *tree2);

예시

tree1 = 1 3 2 5 4 7 8, tree2 = 1 3 2 5 4 7 8 → 구조적으로 같음

입출력 예시

1: 이진 트리 1 만들기.
2: 이진 트리 2 만들기.
3: 두 트리의 구조가 같은지 확인.
0: 종료;

원하는 번호를 입력하세요(1/2/3/0): 1

트리 1 만드는 중:
이진 트리에 추가할 정수를 입력하세요. 문자를 넣으면 NULL 로 처리됩니다.

루트에 넣을 정수: 5
5 의 왼쪽 자식에 넣을 정수: 3
5 의 오른쪽 자식에 넣을 정수: 7
3 의 왼쪽 자식에 넣을 정수: 1
3 의 오른쪽 자식에 넣을 정수: 2
1 의 왼쪽 자식에 넣을 정수: a
1 의 오른쪽 자식에 넣을 정수: a
   ... (이하 같은 방식)
만들어진 트리 1: 1 3 2 5 4 7 8

원하는 번호를 입력하세요(1/2/3/0): 3
두 트리는 구조가 같습니다.
여백 메모 보기 (풀이 힌트 · 스포일러)

둘 다 NULL 이면 return 1.
둘 중 하나만 NULL 이면 return 0.
아니고 item 이 서로 다르면 return 0.
아니면 좌우 서브트리 양쪽을 함께 반환.

2maxHeight

이진 트리의 루트 노드 포인터를 받아서, 루트에서 가장 먼 리프 노드까지 내려가는 경로의 링크 개수를 반환하는 C 함수 maxHeight() 를 작성하세요.

어떤 노드의 높이는 그 노드에서 가장 깊은 리프 노드까지의 링크 개수입니다. 힌트: 빈 트리의 높이는 -1 로 봅니다.

함수 원형

int maxHeight(BTNode *root)

예시

최대 높이: 2 (예: 4 → 2 → 1 로 링크 2개)

여백 메모 보기 (풀이 힌트 · 스포일러)

if null return -1;
아니면 좌우 서브트리를 비교해서, 큰 쪽에 +1 해서 반환.

3countOneChildNodes

이진 트리의 루트 노드 포인터를 받아서, 자식이 정확히 하나뿐인 노드의 개수를 반환하는 C 함수 countOneChildNodes() 를 작성하세요.

함수 원형

int countOneChildNodes(BTNode *root)

예시

자식이 정확히 하나인 노드 개수: 2 (30 은 왼쪽만, 60 은 오른쪽만)

여백 메모 보기 (풀이 힌트 · 스포일러)

if null return 0;
아니고 자식이 하나만 있으면 return 좌 + 우 + 1.
아니면 return 좌 + 우.

4sumOfOddNodes

정수 이진 트리의 루트 노드 포인터를 받아서, 트리에 있는 홀수를 전부 더한 값을 반환하는 재귀 C 함수 sumOfOddNodes() 를 작성하세요.

함수 원형

int sumOfOddNodes(BTNode *root);

예시

홀수 총합: 131 (11 + 35 + 85)

여백 메모 보기 (풀이 힌트 · 스포일러)

if null return 0;
아니고 item 이 홀수면 return 좌 + 우 + item.
아니면 return 좌 + 우.

5mirrorTree

이진 트리를 원래 구조의 거울상으로 바꾸는 재귀 C 함수 mirrorTree() 를 작성하세요.

중간 트리나 임시 트리를 새로 만들면 안 됩니다. 함수는 뒤집을 이진 트리의 루트 노드 포인터 하나만 받습니다.

함수 원형

void mirrorTree(BTNode *node);

예시

tree1 = 5 6 4 3 2 1 → tree2 = 1 2 3 4 6 5

→ 중위 순회 결과가 정확히 뒤집힙니다.

여백 메모 보기 (풀이 힌트 · 스포일러) 
if (node == NULL) return;
else BTNode *temp;
     // temp 로 좌우 서브트리를 맞바꾼다
     mirrorTree(node->left);
     mirrorTree(node->right);

6printSmallerValues

이진 트리의 루트 노드 포인터를 받아서, 주어진 값 m 보다 작은 값을 전부 출력하는 C 함수 printSmallerValues() 를 작성하세요.

함수 원형

void printSmallerValues(BTNode *node, int m);

예시

value = 55 로 호출 → 50, 30, 25, 10 출력

→ 이 트리는 이진 탐색 트리가 아닙니다. 그냥 이진 트리예요.

여백 메모 보기 (풀이 힌트 · 스포일러)

이 문제에서 쓰는 건 전위 순회(preorder) 출력이다.

7smallestValue

주어진 트리에 저장된 가장 작은 값을 반환하는 C 함수 smallestValue() 를 작성하세요. 함수는 트리의 루트 포인터를 받습니다.

함수 원형

int smallestValue(BTNode *node);

예시

최솟값: 10

→ 탐색 트리가 아니라서 “왼쪽 끝까지 내려가면 최솟값” 이 성립하지 않습니다.

8hasGreatGrandchild

이진 트리에서 증손자(great-grandchild)가 하나 이상 있는 노드의 값을 전부 출력하는 재귀 C 함수 hasGreatGrandchild() 를 작성하세요. 함수는 루트 노드 포인터 하나만 받습니다.

함수 원형

int hasGreatGrandchild(BTNode *node);

예시

출력: 50 (50 → 30 → 65 → 20 으로 3대 아래에 증손자가 있음)

→ 30 은 손자(20)까지만 있고 증손자는 없습니다.

여백 메모 보기 (풀이 힌트 · 스포일러)

이 함수가 반환하는 건 현재 node 의 depth 다.
현재 node 의 depth 가 3 이상이면 그 node 의 item 을 출력한다.
반환하는 정수는 depth 다.
